About loldb

loldb is a public statistical analysis and insights database designed for developers and data analysts in the League of Legends community. Our primary goal is to enhance player experience by providing comprehensive statistics, deep gameplay insights, and performance correlations extracted from a large dataset of matches.

By leveraging Riot Games APIs (including Match-V5, Summoner, and Champion APIs), loldb aggregates detailed match timelines, player behaviors, and objective events to offer novel insights into the game mechanics and strategies.

Important: This database is a technical resource intended for developers and data scientists with programming knowledge. Accessing and analyzing the data requires familiarity with programming languages like Python or R, and data analysis techniques.

Our Data
